Připojte svůj GitHub účet a spravujte autory, fotografie a texty na jednom místě.

Token se používá pouze v této otevřené stránce. Po obnovení stránky se přihlásíte znovu.

Jak získám přístupový token?
  1. Na GitHubu otevřete nový fine-grained token.
  2. Vyberte vlastníka MN-sys-cmyk a pouze repozitář WebTest.
  3. V Repository permissions nastavte Contents → Read and write. Ostatní oprávnění nejsou potřeba.
  4. Zvolte expiraci, vytvořte token a vložte jej do pole výše. Neposílejte ho do chatu.

Pro každodenní testování není potřeba účet na jiné službě. Zápis podléhá oprávněním účtu a ochraně větve GitHub.
